# Глоссарий

Две части: термины закупок, которые встречаются в документах и правилах, и термины продукта с их именами в коде. В интерфейсе, в коде и в разговоре с ИИ-ассистентом используем одни и те же слова.

## Закупки

Справка для ориентира команды, не юридическая консультация. Формулировки правил и объяснений в чек-листе согласуем с методологом.

| Термин | Что значит |
| --- | --- |
| 44-ФЗ | Федеральный закон от 05.04.2013 № 44-ФЗ о контрактной системе: закупки для государственных и муниципальных нужд |
| 223-ФЗ | Федеральный закон от 18.07.2011 № 223-ФЗ: закупки отдельных видов юридических лиц, в первую очередь компаний с государственным участием. Правила конкретной закупки задаёт положение о закупке заказчика |
| 615-ПП | Постановление Правительства РФ от 01.07.2016 № 615: закупки региональных операторов (фондов) капитального ремонта |
| Заказчик | Организация, которая проводит закупку и заключает контракт |
| Поставщик (подрядчик, исполнитель), участник закупки | Компания, которая подаёт заявку и исполняет контракт. Наш пользователь работает на этой стороне |
| Тендерный специалист | Сотрудник поставщика, который ищет закупки, изучает документацию и готовит заявки |
| ЭТП | Электронная торговая площадка, на которой проходит закупка |
| РНП | Реестр недобросовестных поставщиков. Туда попадают сведения об участниках, которые уклонились от заключения контракта или с которыми контракт расторгнут из-за существенного нарушения условий. Сведения хранятся в реестре два года; заказчики, как правило, не допускают к закупкам участников из реестра |
| Закупочная документация | Комплект документов закупки: извещение, описание объекта закупки (техническое задание), проект контракта, требования к заявке, обоснование цены. У нас это пакет |
| ТЗ | Техническое задание — описание объекта закупки: что, в каком объёме и с какими характеристиками нужно поставить |
| Проект контракта | Текст будущего контракта. Основной источник рисков: сроки, ответственность, порядок приёмки и оплаты |
| НМЦК | Начальная (максимальная) цена контракта |
| Обеспечение заявки, обеспечение исполнения контракта | Деньги или независимая гарантия, которыми участник подтверждает серьёзность намерений и исполнение обязательств |
| Неустойка (штраф, пеня) | Ответственность за нарушение условий контракта |
| Односторонний отказ | Расторжение контракта по решению одной из сторон. Отказ заказчика из-за нарушений поставщика может стать основанием для включения в РНП |

## Продукт

| Термин в интерфейсе | В коде | Что значит |
| --- | --- | --- |
| Пакет | `Batch` | Одна загрузка: zip-архив или несколько файлов по одной закупке, до 100 МБ |
| Документ | `Document` | Один файл пакета: pdf, docx, doc, rtf |
| Блок | `Block` | Структурная единица текста документа: заголовок, абзац, ячейка таблицы. Знает свой раздел (`section_path`, `section_title`), страницу и координаты |
| Фрагмент | `Chunk` | Кусок текста из нескольких блоков (300–500 токенов) с эмбеддингом для векторного поиска |
| Правило | `Rule` | Одна проверка чек-листа с кодом (`R-04`), названием, уровнем и объяснением для юриста. Типы: regex, ключевые слова, смысловой поиск, проверка ИИ |
| Профиль правил | `RuleProfile` | Набор правил под вид закупки, например «44-ФЗ». Выбирается при загрузке пакета |
| Чек-лист | — | Все правила профиля. Стартовый набор — R-01…R-08 |
| Находка | `Finding` | Сработавшее правило на конкретном фрагменте: цитата, раздел, уровень, объяснение, уверенность |
| Ручная пометка | `Finding` с `source = user` | Находка, которую добавил человек выделением текста |
| Выноска | — | Карточка находки справа от текста в редакторе |
| Уровень | `severity`: `red`, `yellow` | «Критично» или «Внимание». Зелёный — это отсутствие находок, отдельного уровня у находки нет |
| Цвет документа и пакета | — | Худший уровень среди находок внутри. Серый — обрабатывается или ошибка |
| Статус находки | `status`: `new`, `accepted`, `rejected`, `edited` | Результат ревью: новая, принята, отклонена, изменена |
| Ревью | — | Проверка находок юристом: принять, отклонить, изменить, прокомментировать |
| История находки | `FindingEvent` | Кто, когда и что изменил в находке |
| Этап обработки | `TaskRun` | Запись о выполнении одного шага обработки документа: извлечение текста, распознавание, анализ |
| Экспорт | `Export` | Размеченный документ (docx, pdf) или zip пакета со сводным отчётом `Сводка.xlsx` |

## Роли

| Роль | Что делает |
| --- | --- |
| Специалист | Загружает пакеты, смотрит находки, размечает вручную, скачивает результат |
| Юрист | Проверяет находки: принимает, отклоняет, комментирует |
| Методолог | Ведёт чек-лист правил; только эта роль редактирует «Правила» |
