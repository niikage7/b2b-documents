# Светофор рисков — описание интерфейса для дизайнера

4 октября 2026 · автор: Nik Gurtovoy

> Документ перенесён в репозиторий из командного рабочего пространства. Картинки не переносились: на их месте стоят подписи «Макет на холсте», сами макеты смотрите на холсте дизайна по ссылке ниже и в Figma.
> Соседние документы: [условия хакатона](hackathon.md), [распределение задач](tasks.md), [глоссарий](glossary.md).

## Общее

Нужно нарисовать 6 страниц десктопного веб-приложения для юристов и тендерных специалистов. Главное в продукте — быстро увидеть, где в документах пакета риски, и прочитать объяснение к каждому. Целевой экран — 1440 px по ширине, минимальный — 1280 px; мобильная версия и темная тема не нужны. Фирменного стиля пока нет: логотип, шрифты и палитру предлагает дизайнер.

Скриншоты в разделах ниже — фрагменты готовых макетов с [холста дизайна](https://claude.ai/artifact/VqpB6JhZXkoZ9N2EjbXV9t). Полные экраны и все состояния смотрите на холсте.

### Роли

| Роль | Что делает | Что видит |
| --- | --- | --- |
| Специалист | Загружает пакеты, смотрит находки, размечает вручную, скачивает результат | Все страницы, кроме «Правил» |
| Юрист | Проверяет находки: принимает, отклоняет, комментирует | Все страницы, кроме «Правил» |
| Методолог | Ведет чек-лист правил | Все страницы, «Правила» — с редактированием |

### Навигация

- Левая боковая панель на всех страницах после входа: логотип, «Пакеты», «Загрузить пакет», «Правила» (только методологу), внизу — пользователь и «Выйти».
- Хлебные крошки над заголовком: «Пакеты / Закупка\_0001 / Проект\_контракта.docx».
- Главная кнопка действия — «Загрузить пакет» — заметна на странице «Пакеты» и в боковой панели.

### Цвета светофора

Цвет никогда не работает в одиночку: рядом всегда есть подпись или иконка, чтобы интерфейс был понятен людям с нарушением цветовосприятия и при печати в ч/б.

| Уровень | Подпись в интерфейсе | Где используется |
| --- | --- | --- |
| Красный | Критично | Находки и документы с серьезным риском |
| Желтый | Внимание | Находки и документы, которые стоит проверить |
| Зеленый | Без рисков | Документы без находок |
| Серый | Обрабатывается / Ошибка | Документы и пакеты, которые еще не готовы или упали |

Ручные пометки используют те же цвета уровней, что и находки ИИ; отличаются только подписью автора в выноске.

Правило для документа и пакета: цвет = худший уровень среди находок внутри. Документ с двумя критичными находками не может быть зеленым.

### Сквозные компоненты

- **Бейдж уровня**: цветная точка или иконка + подпись («Критично 2»).
- **Карточки-счетчики**: «Всего / Без рисков / Внимание / Критично» с числом; клик фильтрует список под ними, активная карточка выделена.
- **Статус обработки**: «В очереди», «Обрабатывается · этап · 45%», «Готово», «Ошибка» с причиной.
- **Кнопки скачивания** с разными названиями: «Скачать документ» и «Скачать пакет». Две одинаковые «Сохранить» запрещены.
- **Тосты** для коротких подтверждений («Находка отклонена · Отменить»).

### Состояния, которые нужны на каждой странице

Загрузка (скелетоны), пустое состояние с подсказкой, что делать, ошибка с кнопкой «Повторить», нет прав доступа.

## Карта страниц

```text
Авторизация
    └─> Пакеты (стартовая)
            ├─> Загрузка пакета: выбор файлов ─> обработка ─┐
            └─> Разбор пакета <─────────────────────────────┘
                    └─> Редактор документа (переключение между документами пакета)

Правила — из боковой панели, только методологу
```

Схема восстановлена по тексту этого документа; исходная интерактивная карта осталась на холсте.

«Правила» и «Загрузить пакет» доступны из боковой панели на любой странице; из редактора можно переключаться между документами пакета, не возвращаясь на разбор.

## 1. Авторизация

Простой экран входа по логину и паролю; регистрации нет — учетные записи создает администратор.

> **Макет на холсте:** Экран входа: фото слева, форма входа справа

| Блок | Содержимое | Действия |
| --- | --- | --- |
| Логотип и название | «Светофор рисков» + короткая строка о продукте: «Проверка тендерной документации на риски» | — |
| Форма | Поле «Логин или email», поле «Пароль» с кнопкой показать/скрыть | «Войти» (активна, когда заполнены оба поля) |
| Подсказка | «Нет доступа? Обратитесь к администратору» | — |

**Состояния:** пустая форма; отправка (кнопка с индикатором); неверный логин или пароль — сообщение под формой, поля не очищаются; слишком много попыток — «Попробуйте через 5 минут»; сессия истекла — после перехода с другой страницы показать «Сессия завершена, войдите снова».

**После входа** пользователь попадает на страницу «Пакеты».

## 2. Загрузка пакета и статус обработки

Одна страница в двух состояниях: сначала пользователь собирает и отправляет пакет, затем на том же экране следит за обработкой каждого файла. Когда все готово, ведет на «Разбор пакета».

### Состояние А: выбор файлов

> **Макет на холсте:** Загрузка: зона перетаскивания, список файлов с ошибками и параметры проверки

| Блок | Содержимое | Действия |
| --- | --- | --- |
| Заголовок | «Загрузка пакета» | — |
| Зона перетаскивания | Крупная область: «Перетащите файлы или zip-архив сюда» + «Выбрать файлы». Под ней — допустимые форматы (zip, pdf, docx, doc, rtf) и лимит 100 МБ на пакет | Drag-and-drop, выбор через диалог, можно добавлять файлы несколькими порциями |
| Список выбранных файлов | Строка на файл: иконка типа, имя, размер, крестик; для zip — раскрывается список содержимого. Внизу — общий объем «34 МБ из 100» | Удалить файл из списка |
| Параметры | Название пакета (по умолчанию из имени архива), профиль правил — выпадающий список, по умолчанию «44-ФЗ» | Изменить название и профиль |
| Кнопки | «Начать проверку» (главная), «Отмена» | Отправить пакет |

**Ошибки на этом шаге:** неподдерживаемый формат — файл в списке помечен красным с причиной и не отправляется; превышен лимит — счетчик объема красный, кнопка неактивна; файл защищен паролем — предупреждение у файла.

### Состояние Б: обработка

> **Макет на холсте:** Обработка: общий прогресс и этап каждого документа

| Блок | Содержимое | Действия |
| --- | --- | --- |
| Шапка пакета | Название, профиль правил, общий прогресс «Обработано 2 из 3», примерное оставшееся время | «Перейти к разбору» (активна, когда готов хотя бы один документ) |
| Список документов | Строка на документ: имя, тип, число страниц, текущий этап, прогресс-бар, статус. Этапы, которые видит пользователь: «В очереди» → «Извлечение текста» (для сканов — «Распознавание, стр. 4 из 12») → «Анализ» → «Готово» | Для готового — «Открыть»; для ошибки — «Повторить» |
| Итог по готовым | Когда документ готов, в его строке появляется бейдж уровня и число находок | Клик по строке ведет в документ |

**Важно:** прогресс обновляется сам, без перезагрузки. Пользователь может уйти со страницы — обработка продолжается, а пакет виден в списке «Пакеты» со статусом «Обрабатывается». Ошибка одного документа не останавливает остальные: строка серая с иконкой ошибки, причиной («Файл поврежден») и кнопкой «Повторить».

**Когда все готово:** баннер «Проверка завершена · Критично 1 · Внимание 1 · Без рисков 1» и кнопка «Открыть разбор пакета».

## 3. Все пакеты

Стартовая страница после входа: список всех пакетов пользователя, новые сверху. Задача экрана — за секунды найти нужный пакет и понять, где критичные риски.

> **Макет на холсте:** Список пакетов с фильтрами, находками и статусами

| Блок | Содержимое | Действия |
| --- | --- | --- |
| Заголовок | «Пакеты» + кнопка «Загрузить пакет» справа | Перейти к загрузке |
| Панель фильтров | Поиск по названию пакета или файла; фильтр по статусу (Все / Обрабатывается / Готово / Ошибка); фильтр по худшему уровню (Критично / Внимание / Без рисков); период загрузки; переключатель «Мои / Все» (для юристов, которые смотрят чужие пакеты) | Фильтрация без перезагрузки |
| Таблица пакетов | Колонки: цвет (худший уровень), название, дата и время загрузки, автор, профиль правил, документов, находки «Критично · Внимание», статус, меню действий | Клик по строке — «Разбор пакета»; меню: «Скачать пакет», «Переименовать», «Удалить» |
| Строка обрабатываемого пакета | Вместо счетчиков — прогресс «2 из 3» | Клик ведет на экран обработки |
| Пагинация | По 20 пакетов, внизу страницы | — |

**Состояния:** пустое — иллюстрация, «Пока нет пакетов» и кнопка «Загрузить первый пакет»; ничего не найдено по фильтрам — «Сбросить фильтры»; удаление — диалог подтверждения с названием пакета.

## 4. Разбор пакета

Сводка по одному пакету: какие документы в нем есть, где риски и какие именно. Отсюда пользователь переходит в конкретный документ или скачивает весь пакет с отчетом.

> **Макет на холсте:** Разбор пакета: счётчики, документы и сработавшие правила

| Блок | Содержимое | Действия |
| --- | --- | --- |
| Шапка | Название пакета, дата, автор, профиль правил, статус ревью «Проверено 5 из 12 находок» | «Скачать пакет» (zip со всеми документами + сводный отчет), меню: «Перезапустить проверку», «Удалить» |
| Карточки-счетчики | По документам: «Всего 3 · Без рисков 1 · Внимание 1 · Критично 1» | Клик фильтрует список документов |
| Список документов | Карточка или строка на документ: иконка типа, имя, страниц, бейдж худшего уровня, число находок по уровням, прогресс ревью («2 из 5 проверено»), пометка «скан» и качество распознавания, если оно низкое | Клик — «Редактор документа»; «Скачать документ» |
| Все находки пакета | Таблица-альтернатива списку документов (переключатель вкладок «Документы / Находки»): уровень, правило, документ, раздел, короткая цитата, статус (новая / принята / отклонена) | Сортировка и фильтр по уровню, правилу, статусу; клик открывает документ сразу на этой находке |
| Сводка по правилам | Компактный блок: какие правила сработали и сколько раз, например «R-04 Срок поставки — 2» | Клик фильтрует находки по правилу |

**Состояния:** пакет еще обрабатывается — готовые документы доступны, остальные со статусом и прогрессом; документ с ошибкой — серый, причина и «Повторить»; в документе нет находок — зеленый бейдж «Без рисков» и кнопка «Открыть» все равно доступна.

**Порядок документов по умолчанию:** сначала критичные, затем «Внимание», затем «Без рисков» — так юрист начинает с важного.

## 5. Редактор и просмотр документа

Главный рабочий экран: текст документа с цветной подсветкой рискованных фрагментов и выносками справа. Здесь юрист читает объяснения, принимает или отклоняет находки и добавляет свои пометки. Это самый важный макет — на него стоит потратить больше всего времени.

### Раскладка

> **Макет на холсте:** Редактор документа: список документов, текст с подсветкой и выноски справа

Выноски стоят на уровне своих фрагментов. Если места не хватает, выноска сдвигается ниже и сворачивается в одну строку — так на скриншоте свёрнуты R-07 и R-08. Наложений нет.

| Зона | Содержимое | Действия |
| --- | --- | --- |
| Панель документов слева (узкая, сворачивается) | Документы пакета с бейджами уровней, текущий выделен | Переключение документа без возврата на «Разбор пакета» |
| Верхняя панель | Хлебные крошки, имя документа, счетчики находок «Критично 2 · Внимание 3 · Ручные 1» как фильтры, навигация «← Предыдущая · 3 из 6 · Следующая →», поиск по тексту, для сканов — переключатель «Текст / Оригинал» | «Скачать документ»; фильтр по уровню и статусу («Показать отклоненные») |
| Текст документа по центру | Документ как читаемый текст: заголовки разделов с номерами, абзацы, таблицы; номер страницы на полях. Подсвечен ровно фрагмент цитаты цветом уровня, без рамок поверх строк | Выделение мышью для ручной пометки; клик по подсветке активирует выноску |
| Колонка выносок справа | Карточка на каждую находку на уровне ее фрагмента; выноски не налезают друг на друга — при тесноте сдвигаются вниз, тонкая линия соединяет выноску с началом фрагмента | Наведение и клик синхронизированы с подсветкой; кнопки в карточке |

### Карточка выноски

> **Макет на холсте:** Подробная выноска R-04 рядом с фрагментом и компактные выноски справа

- Бейдж уровня и название правила: «Критично · R-04 Срок поставки короче разумного».
- Ссылка на раздел: «п. 3.2 «Сроки поставки», стр. 5» — клик прокручивает к началу раздела.
- Объяснение риска в 1–3 предложения.
- Источник: «ИИ» или имя автора для ручной пометки; для находок ИИ — уверенность «высокая», «средняя» или «низкая» (подпись или индикатор из трех делений с подсказкой при наведении).
- Кнопки: «Принять», «Отклонить», «Изменить» (уровень и комментарий), меню «История».
- Поле комментария юриста — раскрывается по клику.
- Свернутое состояние: только бейдж и название правила, разворачивается по клику.

**Статусы карточки:** новая (по умолчанию), принята (галочка, карточка спокойнее), отклонена (скрыта, видна только с фильтром «Показать отклоненные», серая, подсветка в тексте пунктирная или убрана), изменена (пометка «изменено»).

### Ручная пометка

> **Макет на холсте:** Новая ручная пометка на выделенном тексте

1. Пользователь выделяет текст мышью.
2. Рядом появляется всплывающее меню: выбор уровня («Критично / Внимание»), поле «Комментарий», кнопки «Добавить» и «Отмена».
3. После добавления фрагмент подсвечивается цветом выбранного уровня, как находка ИИ; справа появляется выноска с именем автора и временем.

### Поведение

- Наведение на подсветку — выделяется ее выноска, и наоборот; клик закрепляет выбор и прокручивает к парной части.
- «Следующая / Предыдущая» прокручивает текст к фрагменту и открывает выноску; горячие клавиши J / K.
- Изменения сохраняются сразу; тост «Находка отклонена · Отменить».
- Скан в режиме «Оригинал»: изображение страницы, поверх — полупрозрачная подсветка тех же фрагментов; страницы с плохим распознаванием помечены.

**Состояния:** документ без находок — зеленая плашка «Рисков не найдено» над текстом, ручная пометка доступна; документ еще обрабатывается — заглушка с прогрессом; длинный документ (100+ страниц) — подгрузка по мере прокрутки, мини-карта находок на полосе прокрутки (цветные засечки) — желательно.

## 6. Правила

Экран методолога: здесь ведут чек-лист рисков без участия программистов. Пользователь должен понимать, что делает правило, не читая регулярные выражения и промпты.

> **Макет на холсте:** Правила: вкладки профилей, таблица правил и редактор правила с проверкой на документе

> **Макет на холсте:** Раскрытые переменные инструкции

| Блок | Содержимое | Действия |
| --- | --- | --- |
| Профили слева | Список профилей: «44-ФЗ, поставка товаров», «223-ФЗ», «Коммерческие»; у профиля по умолчанию — пометка | Выбрать, создать, переименовать, сделать профилем по умолчанию |
| Таблица правил | Колонки: переключатель вкл/выкл, код (R-04), название, уровень (бейдж), тип (Regex / Ключевые слова / Смысловой поиск / Проверка ИИ), сколько раз сработало за 30 дней, дата изменения | Поиск, фильтр по уровню и типу; «Новое правило»; клик открывает редактор |
| Редактор правила (боковая панель справа или отдельный экран) | Общие поля: код, название, описание для юриста (это объяснение попадет в выноску), уровень, тип. Поля зависят от типа: для Regex — шаблоны; для ключевых слов — список слов-тегов; для смыслового поиска — поисковый запрос; для проверки ИИ — запрос и текст инструкции с подсказками переменных | «Сохранить», «Отмена», «Удалить» с подтверждением |
| Тест правила (внутри редактора) | Поле для вставки текста или выбор загруженного документа; результат — найденные фрагменты с подсветкой и объяснением, или «Ничего не найдено» | «Проверить» (до сохранения) |

**Состояния:** нет прав — специалист и юрист видят правила только для чтения или пункт меню скрыт; тест выполняется — индикатор до 60 с; ошибка в шаблоне — подсветка поля с понятной причиной; несохраненные изменения — предупреждение при уходе со страницы.

**Важно:** изменение правила действует только на новые пакеты — об этом стоит написать в редакторе одной строкой.

**Принятые решения**

- Ручные пометки и находки ИИ — одного цвета, различаются подписью автора.
- Фирменного стиля нет: логотип, шрифты и палитру предлагает дизайнер.
- Темная тема не нужна.
- Уверенность ИИ показывается юристу в каждой выноске.
